Все три HTML-файла должны находиться в корне репозитория.
Главная уже использует ./switchflow.html и ./color_fuse.html.
В обе игры добавлена ссылка «← К выбору игр» на ./index.html.
Внешних ресурсов нет. Ссылки относительные, поэтому страницы работают
в подпапке репозитория GitHub Pages. Исходные игровые скрипты сохранены.

ПУБЛИКАЦИЯ ЧЕРЕЗ ВЕБ-ИНТЕРФЕЙС GITHUB
1. Войди на github.com и создай новый публичный репозиторий puzzle-lab.
2. Распакуй готовый ZIP на своём компьютере.
3. В репозитории выбери Add file → Upload files и загрузи содержимое
   комплекта. Загружай файлы, а не ZIP. index.html должен быть в корне.
4. Нажми Commit changes и сохрани файлы в ветку main.
5. Открой Settings → Pages.
6. В Build and deployment выбери Source → Deploy from a branch.
7. Выбери Branch → main, Folder → / (root), затем Save.
8. Дождись успешного развёртывания. Его состояние доступно во вкладке
   Actions, а адрес опубликованного сайта — в Settings → Pages.
9. Открой выданный GitHub адрес на телефоне. Для репозитория puzzle-lab
   он обычно имеет вид https://<логин>.github.io/puzzle-lab/.
10. Проверь открытие обеих игр, выполнение игровых действий, переход
    на следующий уровень, перезапуск и возврат к выбору игр. Затем открой
    каждую игру по прямой ссылке и обнови страницу.

Официальная инструкция:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

ПРОВЕРКА КОМПЛЕКТА (26.10.2026)
Все 8 уровней каждой игры пройдены через интерфейс браузера.
Проверены неверный маршрут SwitchFlow, проигрыш Color Fuse, отмена,
перезапуск и возврат на главную. Отдельная модель подтвердила решаемость
16 уровней и совпадение правил расчёта с исходным движком.
На ширинах 320, 375 и 430 px у трёх страниц нет горизонтального переполнения.
Проверка выполнена в браузере компьютера; на реальном телефоне и в Safari
тестирование не проводилось. Полная кроссбраузерная проверка не заявляется.
