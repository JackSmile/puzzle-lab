HTML-файлы должны находиться в корне репозитория.
Для Duskbound также сохрани папку games/ со всей её структурой.
Главная уже использует ./switchflow.html и ./color_fuse.html.
В обе игры добавлена ссылка «← К выбору игр» на ./index.html.
Внешних ресурсов нет. Ссылки относительные, поэтому страницы работают
в подпапке репозитория GitHub Pages. Исходные игровые скрипты сохранены.

ПУБЛИКАЦИЯ ЧЕРЕЗ ВЕБ-ИНТЕРФЕЙС GITHUB
1. Войди на github.com и создай новый публичный репозиторий puzzle-lab.
2. Распакуй готовый ZIP на своём компьютере.
3. В репозитории выбери Add file → Upload files и загрузи содержимое
   комплекта. Загружай файлы, а не ZIP. index.html должен быть в корне.
4. Нажми Commit changes и сохрани файлы в ветку main.
5. Открой Settings → Pages.
6. В Build and deployment выбери Source → Deploy from a branch.
7. Выбери Branch → main, Folder → / (root), затем Save.
8. Дождись успешного развёртывания. Его состояние доступно во вкладке
   Actions, а адрес опубликованного сайта — в Settings → Pages.
9. Открой выданный GitHub адрес на телефоне. Для репозитория puzzle-lab
   он обычно имеет вид https://<логин>.github.io/puzzle-lab/.
10. Проверь открытие всех трёх игр, выполнение игровых действий, переход
    на следующий уровень, перезапуск и возврат к выбору игр. Затем открой
    каждую игру по прямой ссылке и обнови страницу.

Официальная инструкция:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

DUSKBOUND
Открой duskbound.html через HTTP: ES-модули требуют обычный веб-сервер.
Локально: python3 -m http.server 4173 --bind 127.0.0.1
Адрес: http://127.0.0.1:4173/duskbound.html
Движение: WASD / стрелки; на телефоне — экранный джойстик.
Атаки автоматические. На новом уровне выбери камень; поддержку свяжи
с подходящим умением. Элитные враги с золотым контуром оставляют предметы.
Пауза: Esc / P. Камни и экипировка: B или кнопка ◈.
Продержись 8 минут и победи Brutus, Merveil, Dominus и Kitava.
Встречи открываются на 02:00, 04:00, 06:00 и 07:30. Если предыдущий
босс ещё жив, следующий ждёт в очереди; бой может продолжиться после 08:00.
Семь классов и 21 восхождение PoE 1: по четыре ключевых узла,
восемь очков на исходные пути. Испытания: 90, 180, 300 и 420 секунд.
На экране персонажа распределяй очки характеристик, полученные с уровнем.
Пять активных умений, восемь поддержек, уникальная добыча.
Источники, оригинальные числа и границы адаптации:
docs/poe-references.md, docs/poe-classes-sources.md,
docs/duskbound-classes-report.md, docs/poe-unique-sources.md.
Дизайн: docs/duskbound-design.md. Графика: docs/duskbound-assets.md.
Рекорды и настройки сохраняются локально. Забег и добыча начинаются заново
при следующей попытке. Пауза включается при уходе со вкладки.
Игра не требует npm install, сборки или загрузки внешних ресурсов.
