# Duskbound: оригинальные inventory icons для 12 новых unique

Получено 27 октября 2026 года. Скачаны 12 исходных PNG из основной карточки каждого текущего обычного предмета PoE Wiki. Replica, Foulborn, relic/alternate art и изображения базовых неуникальных предметов не использованы. Исходные байты не преобразовывались и не масштабировались.

Метод: CUA в этом продолжении не предоставил ни одного браузера (`iab` недоступен). Использован разрешённый сетевой `curl` к публичным страницам и PNG без секретов. URL взят из `src` первого inventory image основной item-card; у Daresso исходный full-size URL взят из явно указанного `srcset` той же карточки. Это чтение HTML, а не измерение DOM `img.currentSrc`; выбор browser DPR не заявляется.

Ссылки на редакции фиксируют источник карточки на момент получения. Изображения — Path of Exile / Grinding Gear Games, источник размещения — PoE Wiki.

## Проверки

- Ровно 12 новых файлов с запрошенными slug; суммарно 379,873 bytes.
- Все ответы успешно скачаны с HTTP failure checking; PNG signature, IHDR dimensions и SHA-256 проверены.
- Каждый файл полностью декодирован Pillow; размеры совпали с `data-file-width` / `data-file-height` исходной карточки.
- Визуально просмотрена контактная сетка всех 12: предметы различимы, показаны inventory icons, фон прозрачный. Контактная сетка создана только во временной директории для QA; игровые PNG сохранены в оригинальном размере.
- Реализация UI и screenshot готового интерфейса в этот asset-only этап не входили. Проверка не подтверждает читабельность иконок после уменьшения в UI.
