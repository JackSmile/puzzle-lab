# Дополнительные визуальные источники Duskbound

Дата просмотра: 2026-10-27. Просмотрены реальные кадры воспроизводимых видео через CUA, а не только описания навыков. Ассеты игры не скачивались и не извлекались. Ниже отдельно отмечены наблюдения, сведения о механике и ограничения источников. Это материал для самостоятельной визуальной интерпретации, не импорт оригинальных эффектов.

## Blade Vortex — сильный исторический источник базового эффекта

- Источник: [Path of Exile — Blade Vortex Skill Demonstration](https://www.youtube.com/watch?v=rCro9h8reZw), официальный верифицированный канал Path of Exile. Описание видео прямо называет демонстрацию нового навыка для 2.1.0/Talisman.
- Просмотренные кадры: [0:02](https://www.youtube.com/watch?v=rCro9h8reZw&t=2s), [0:15](https://www.youtube.com/watch?v=rCro9h8reZw&t=15s).
- Наблюдается: вокруг персонажа несколько разорванных круговых следов бледного мятного/зелёно-бирюзового цвета. Следы тонкие, полупрозрачные; местами различимы короткие вытянутые клинки/светлые полосы. Центр и силуэт персонажа остаются видимыми. Эффект окружает игрока на небольшой дистанции и сохраняется вокруг него при смене положения в бою.
- Для визуального переноса: круговые траектории с отдельными клинками, короткими светлыми головами и затухающими дугами. Не сплошной непрозрачный диск и не набор крупных неподвижных мечей.
- Ограничение: это базовая официальная демонстрация 2015 года. Она не доказывает, что современный base VFX ни разу не менялся. На 0:15 одновременно присутствуют огонь, молнии и другие эффекты боя; не переносить их в Blade Vortex. Отдельная вспышка попадания/точная фаза каста не изолирована.

## Raise Spectre — реальный PoE1 gameplay, силуэт зависит от монстра

- Источник: [Path of Exile Skill Gem Raise Spectre](https://www.youtube.com/watch?v=wRkCjyZmcpM), Barbarian Bear, старое PoE1 gameplay (~12 лет на момент просмотра).
- Просмотренные точки: [2:40](https://www.youtube.com/watch?v=wRkCjyZmcpM&t=160s) — выделен Goatman (Corpse); [2:50](https://www.youtube.com/watch?v=wRkCjyZmcpM&t=170s) — рядом с игроком уже стоит призрачное существо; [3:00](https://www.youtube.com/watch?v=wRkCjyZmcpM&t=180s) и [3:08](https://www.youtube.com/watch?v=wRkCjyZmcpM&t=188s) — два призрака сражаются рядом с врагами.
- Наблюдается: полноценный светло-голубой, почти белый полупрозрачный силуэт существа, с читаемыми ногами/телом/позой. Это отдельный от игрока персонаж; он перемещается к врагам. В бою отдельные кадры уходят в лилово-розовый оттенок. На 3:08 видны два призрачных тела около врагов, а игрок находится ниже.
- Механика, независимо проверенная по [PoE Wiki: Skill functions and interactions](https://www.poewiki.net/wiki/Raise_Spectre#Skill_functions_and_interactions): поднятые монстры обычно сохраняют базовые умения из жизни, с оговорёнными исключениями. Поддержка снарядов влияет только на призраков с projectile abilities. Следовательно, нельзя задавать универсальный снаряд как «оригинальный эффект Raise Spectre».
- Для визуального переноса: полупрозрачное тело с мягким холодным свечением и собственной позой/движением. При необходимости проектного projectile-умения явно назвать выбранный тип призрака или обозначить это как игровую интерпретацию Duskbound.
- Ограничения: косметический инвентарь в просмотренных кадрах не проверен; отсутствие MTX не доказано. Источник исторический. Сам момент превращения трупа в призрака не удалось изолировать, поэтому форма/длительность cast burst не подтверждены. Оранжевые огненные снаряды в боевом кадре нельзя приписывать универсальному Raise Spectre.

## Righteous Fire — огненная форма найдена, отсутствие MTX строго не подтверждено

- Наиболее полезный просмотренный gameplay: [Pohx — POE1 | 3.26 Act 1-10 Righteous Fire Chieftain Guide + Commentary](https://www.youtube.com/watch?v=2rCCyxWQsN4).
- Просмотрены [2:30:00](https://www.youtube.com/watch?v=2rCCyxWQsN4&t=9000s) и [2:30:33](https://www.youtube.com/watch?v=2rCCyxWQsN4&t=9033s), бой с Malachai.
- Наблюдается: замкнутый оранжево-золотой горящий круг вокруг игрока. По краю — неровные мелкие языки/искры и местами тонкие холодно-светлые фрагменты; внутри земля остаётся видимой, по ней разбросаны редкие золотые огненные точки. Круг следует за перемещающимся персонажем, не превращается в волну, улетающую от центра. Дополнительное компактное фиолетово-оранжевое свечение непосредственно на персонаже не изолировано от остальных баффов и не считается частью RF.
- Это чистый от звёздного заполнения огненный референс, но UI косметики не показан: статус «base без MTX» доказать по этим кадрам нельзя. Не утверждать точное совпадение с оригинальным base VFX. Вспышка активации не наблюдалась.
- Текстовый источник [PoE Wiki: Righteous Fire](https://www.poewiki.net/wiki/Righteous_Fire) подтверждает instant cast, окружение магическим огнём и постоянный burning damage рядом с игроком. Это механика, не доказательство цвета/рисунка VFX.
- Отклонённые для baseline видео: [Phoenix 3.19](https://www.youtube.com/watch?v=u7-hZDv8o04) и [Phoenix 3.28](https://www.youtube.com/watch?v=7pq6dMeT17w), первые секунды. Оба показывают золотой огненный обод с явным фиолетово-синим звёздным заполнением. Вероятен Celestial MTX; использовать такую текстуру как базовый RF нельзя.

## Границы вывода

Уверенно подтверждён исторический официальный базовый Blade Vortex. Для Raise Spectre подтверждены реальные призрачные существа и зависимость их атак от типа монстра. Для Righteous Fire найден пригодный огненный gameplay-референс, но строгое отсутствие MTX осталось неподтверждённым. Нельзя называть самостоятельно нарисованные эффекты Duskbound извлечёнными/перенесёнными оригинальными анимациями PoE1.
