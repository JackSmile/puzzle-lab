27.10.2026. Внесены локальные исправления двух P2 из `task-4-review.md` и компактная desktop-компоновка. Изменены только `games/duskbound/bestiary-render.mjs`, `games/duskbound/bestiary.mjs`, `games/duskbound/bestiary.css` и этот отчёт.

## Изменения

- Линейный путь предупреждения теперь capsule: отрезок обведён областью радиуса `width / 2`, включая два полукруглых торца. Один и тот же путь используется для обычных и уменьшенных эффектов, а также активного предупреждения.
- Для замаха `rhoaCharge` ширина маркера вычисляется из фактического `enemy.radius * 2`: штатная Rhoa с радиусом 20 даёт ширину 40, fixture с радиусом 26 — 52. Фиксированное `action.width = 38` больше не определяет изображение Rhoa. Chain Pull сохраняет модельную ширину 32. Радиус цели в изображение не добавляется: модель учитывает его при столкновении тела цели с capsule.
- При выборе записи внутри той же вкладки picker обновляет `aria-pressed` существующих кнопок. Кнопка с фокусом и scroll position не уничтожаются. `replaceChildren()` остаётся только для изменения набора записей при смене вкладки; программного переноса фокуса на picker нет.
- На ширине от 701 px уменьшены верхний отступ страницы, отступы ссылки/заголовка/вкладок; desktop canvas уменьшен с 440 до 360 px. Мобильная высота canvas 370 px сохранена. Правки не ограничивают высоту блока управления и не обрезают его содержимое.
